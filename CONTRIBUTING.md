# Contributing to OmniPull

Thanks for improving OmniPull.

1. Open an issue before substantial work so the problem and shape of the change are agreed first.
2. Keep each pull request focused and explain the user-visible impact.
3. Add or update tests for backend behaviour.
4. Run `python -m pytest` and `ruff check backend tests` before opening a pull request.
5. Never include downloaded media, browser data, credentials, or local environment files.
